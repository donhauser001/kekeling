# 图标系统统一改造方案

> 目标：确保后台管理、终端预览器、小程序三端图标完全一致
> 优先级：P0（小程序后天上线）
> 原则：以小程序用户端为准，反向改造整个图标系统

---

## 一、现状分析

### 1.1 当前图标来源

| 平台 | 图标来源 | 问题 |
|------|----------|------|
| 后台管理 | lucide-react (SVG) | ✅ 清晰，但与小程序不一致 |
| 终端预览器 | lucide-compat → iconfont/Unicode | ⚠️ 映射不完整 |

## 五、长期维护

1. **图标添加流程**
   - 先在 iconfont 添加
   - 更新 miniapp.tsx 映射
   - 更新 lucide-compat.tsx
   - 更新后台图标选择器
   - 提交 PR 时必须包含三处修改

2. **图标命名规范**
   - 使用英文小写
   - 使用 kebab-case
   - 与 lucide-react 命名保持一致（方便搜索参考）

3. **禁止事项**
   - ❌ 禁止使用 emoji
   - ❌ 禁止使用 Unicode 符号作为图标（如 ✓ ★ →）
   - ❌ 禁止三端使用不同图标名称
