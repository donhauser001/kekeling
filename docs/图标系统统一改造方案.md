## 二、管理后台使用方式

### 2.1 AppIcon 组件 - 显示单个图标

```tsx
import { AppIcon } from '@/components/ui/icon-picker'

// 基础用法
<AppIcon name="hospital" />

// 指定大小（单位：px，默认 24）
<AppIcon name="shield" size={32} />

// 指定颜色
<AppIcon name="check-one" color="#52c41a" />

// 使用 Tailwind 类名
<AppIcon name="stethoscope" className="text-emerald-500" />

// 组合使用
<AppIcon 
  name="heart" 
  size={20} 
  className="text-red-500 hover:text-red-600 transition-colors" 
/>
```

**Props 说明：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| name | IconName | - | 图标名称（必填） |
| size | number | 24 | 图标大小（px） |
| color | string | currentColor | 图标颜色 |
| className | string | - | 额外的 CSS 类名 |
| style | CSSProperties | - | 内联样式 |

### 2.2 IconPicker 组件 - 图标选择器

用于表单中让用户选择图标，支持搜索和分类浏览。

```tsx
import { IconPicker } from '@/components/ui/icon-picker'
import { useState } from 'react'

function MyForm() {
  const [selectedIcon, setSelectedIcon] = useState<string>('hospital')

  return (
    <IconPicker
      value={selectedIcon}
      onChange={setSelectedIcon}
      placeholder="选择图标"
    />
  )
}
```

**与表单库配合使用：**

```tsx
// React Hook Form 示例
import { useForm, Controller } from 'react-hook-form'
import { IconPicker } from '@/components/ui/icon-picker'

function ServiceForm() {
  const { control } = useForm({
    defaultValues: {
      icon: 'stethoscope',
    },
  })

  return (
    <Controller
      name="icon"
      control={control}
      render={({ field }) => (
        <IconPicker
          value={field.value}
          onChange={field.onChange}
          placeholder="选择服务图标"
        />
      )}
    />
  )
}
```

**Props 说明：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| value | IconName | - | 当前选中的图标 |
| onChange | (name: IconName) => void | - | 选择回调 |
| disabled | boolean | false | 是否禁用 |
| className | string | - | 按钮额外类名 |
| placeholder | string | '选择图标' | 占位文本 |

### 2.4 旧图标名称兼容

IconPicker 内置了旧图标名到新图标名的映射，支持以下 lucide-react 图标名称：


## 三、小程序宿主壳使用方式

### 3.1 Icon 组件 - 基础用法

```tsx
import Icon from '@/components/Icon'
// 或
import { Icon } from '@/components'

// 基础用法
<Icon name="hospital" />

// 指定大小（单位：px，默认 24）
<Icon name="shield" size={32} />

// 指定颜色
<Icon name="check-one" color="#52c41a" />

// 添加额外类名
<Icon name="stethoscope" className="custom-icon" />

// 点击事件
<Icon name="setting" onClick={() => console.log('clicked')} />
```

**Props 说明：**

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| name | IconName | - | 图标名称（必填） |
| size | number | 24 | 图标大小（px） |
| color | string | currentColor | 图标颜色 |
| className | string | '' | 额外的 CSS 类名 |
| style | CSSProperties | - | 内联样式 |
| onClick | () => void | - | 点击事件 |

### 3.2 使用预定义常量

```tsx
import Icon, { IconNames } from '@/components/Icon'

// 使用预定义常量，避免拼写错误
<Icon name={IconNames.HOSPITAL} />
<Icon name={IconNames.SHIELD} />
<Icon name={IconNames.CHECK_ONE} />
<Icon name={IconNames.SHOPPING_CART} />
```

### 3.3 在列表中使用

```tsx
import Icon from '@/components/Icon'
import { View, Text } from '@tarojs/components'

const menuItems = [
  { icon: 'transaction-order', label: '我的订单' },
  { icon: 'wallet', label: '我的钱包' },
  { icon: 'coupon', label: '优惠券' },
  { icon: 'setting', label: '设置' },
]

function MenuList() {
  return (
    <View className="menu-list">
      {menuItems.map((item) => (
        <View key={item.label} className="menu-item">
          <Icon name={item.icon} size={40} color="#333" />
          <Text>{item.label}</Text>
        </View>
      ))}
    </View>
  )
}
```

## 七、注意事项

### 7.1 命名规范
   - 使用英文小写
- 使用 kebab-case（如 `check-one`）
- 与 iconfont 项目中的命名保持一致

### 7.2 禁止事项
   - ❌ 禁止使用 emoji
   - ❌ 禁止使用 Unicode 符号作为图标（如 ✓ ★ →）
   - ❌ 禁止三端使用不同图标名称
- ❌ 禁止使用内联 SVG（影响一致性）

### 7.3 尺寸建议

| 使用场景 | 后台（px） | 小程序宿主壳（px） |
|----------|-----------|-------------------|
| 按钮图标 | 16-18 | 16-18 |
| 列表图标 | 20-24 | 20-24 |
| 标题图标 | 24-32 | 24-32 |
| 大型展示 | 48-64 | 48-64 |

### 7.4 性能优化
- 字体文件已内置，无需网络加载
- 图标按需使用，不影响包体积
- 支持 H5 和小程序双端
