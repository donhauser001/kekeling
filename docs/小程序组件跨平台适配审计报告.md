## 二、根因分析

### 2.1 现象

- **首页 (pages/main/index)**: 正常渲染
- **服务页 (pages/services/index)**: 组件渲染但布局崩溃

### 2.2 根因

小程序侧 Tailwind 不完整，`className` 中的样式类无法生效，导致布局丢失。

**对照验证**：

| 组件 | 写法 | 结果 |
|------|------|------|
| BrandSection | className + 完整 style | ✅ 正常 |
| CategorySection | className + 完整 style | ✅ 正常 |
| ServicesPage | className + 部分 style | ❌ 布局崩 |

## 三、硬性规则（Code Review 判定标准）

### 规则 1：布局与结构样式必须在 style 中完整表达

**强制项**（小程序不允许只靠 className）：

| 属性类别 | 必须在 style 中定义的属性 |
|----------|--------------------------|
| Flex 布局 | `display`, `flexDirection`, `alignItems`, `justifyContent`, `gap`, `flex`, `flexWrap`, `flexShrink`, `flexGrow` |
| Grid 布局 | `display: 'grid'`, `gridTemplateColumns`, `gridGap` |
| 定位 | `position`, `top`, `right`, `bottom`, `left`, `zIndex` |
| 尺寸 | `width`, `height`, `minWidth`, `minHeight`, `maxWidth`, `maxHeight` |
| 溢出 | `overflow`, `overflowX`, `overflowY` |

**判定标准**：
```tsx
// ❌ 不通过：flex 布局只在 className
<Box className='flex items-center gap-2'>

// ✅ 通过：style 中有完整等效
<Box
  className='flex items-center gap-2'
  style={{
    display: 'flex',
    alignItems: 'center',
    gap: 8,
  }}
>
```

---

### 规则 2：className 只允许承载「Web 优化」，不得成为「唯一来源」

**允许 className 单独存在**（非布局关键）：
- 语义类：`text-sm`, `font-medium`, `font-bold`
- 圆角类：`rounded-lg`, `rounded-full`（建议 style 补等效）
- 过渡类：`transition-all`, `duration-200`（小程序会忽略，无害）

**禁止 className 作为唯一来源**（布局关键）：
- `flex`, `inline-flex`, `grid`, `block`, `hidden`
- `items-*`, `justify-*`, `gap-*`, `space-*`
- `w-*`, `h-*`, `min-h-*`, `max-w-*`
- `p-*`, `m-*`, `px-*`, `py-*`, `pt-*`, `pb-*`, `pl-*`, `pr-*`
- `absolute`, `relative`, `fixed`, `sticky`
- `top-*`, `left-*`, `right-*`, `bottom-*`, `z-*`
- `overflow-*`

**判定标准**：
```tsx
// ❌ 不通过：min-h-full 是布局关键，只有 className
<Box className='min-h-full pb-14' style={{ backgroundColor: bgColor }}>

// ✅ 通过：布局属性在 style 中完整定义
<Box
  className='min-h-full pb-14'
  style={{
    minHeight: '100%',
    paddingBottom: 56,
    backgroundColor: bgColor,
  }}
>
```

---

### 规则 3：wxScale 只作用于「视觉尺寸」，不作用于「逻辑布局」

**定义**：
```tsx
import { isWxEnvironment } from '../../platform/env'
const wxScale = isWxEnvironment() ? 1.15 : 1
```

**必须乘 wxScale**（视觉尺寸）：

| 属性 | 示例 |
|------|------|
| 字号 | `fontSize: 14 * wxScale` |
| 行高 | `lineHeight: 20 * wxScale` |
| 图标尺寸 | `width: 24 * wxScale, height: 24 * wxScale` |
| 间距 | `padding: 12 * wxScale`, `gap: 8 * wxScale`, `margin: 16 * wxScale` |
| 圆角 | `borderRadius: 8 * wxScale` |

**禁止乘 wxScale**（逻辑布局）：

| 属性 | 说明 |
|------|------|
| `flex: 1` | 弹性比例，不是尺寸 |
| `display`, `flexDirection` | 结构属性 |
| `alignItems`, `justifyContent` | 对齐方式 |
| `position` | 定位方式 |
| `zIndex` | 层级顺序 |
| 百分比值 | 如 `width: '100%'` |

**判定标准**：
```tsx
// ❌ 不通过：flex: 1 乘了 wxScale
style={{ flex: 1 * wxScale }}

// ❌ 不通过：fontSize 没乘 wxScale
style={{ fontSize: 14 }}

// ✅ 通过
style={{
  flex: 1,                    // 逻辑布局，不乘
  fontSize: 14 * wxScale,     // 视觉尺寸，乘
  gap: 8 * wxScale,           // 视觉尺寸，乘
}}
```

## 四、项目战略选择

### 确定采用方案

**默认采用「双重样式」模式（className + 完整 style）**

| 方案 | 采用度 | 说明 |
|------|--------|------|
| 双重样式 | **主力** | 所有新代码、改造代码必须遵守 |
| app.scss 补丁 | 兜底 | 只做紧急兜底，不作为依赖 |
| 自动转换工具 | 不采用 | 当前阶段不引入额外复杂度 |

### 理由

1. **app.scss 会失控膨胀**：走"类库维护路线"，每新增一个 Tailwind 类都要手动补
2. **双重样式可控**：代码冗余但行为确定，迁移阶段稳定优先
3. **便于 Code Review**：有明确判定标准，不依赖对 app.scss 的记忆

## 五、代码模板

### 5.1 标准组件结构

```tsx
import { Box, Text, Image, Button } from '../../ui/primitives'
import { isWxEnvironment } from '../../platform/env'

// 1. 定义缩放比例
const wxScale = isWxEnvironment() ? 1.15 : 1

export function MyComponent({ isDarkMode }: { isDarkMode?: boolean }) {
  // 2. 定义颜色变量
  const bgColor = isDarkMode ? '#1a1a1a' : '#ffffff'
  const textColor = isDarkMode ? '#e5e7eb' : '#1f2937'

  return (
    // 3. 容器：布局属性必须在 style
    <Box
      className='flex flex-col min-h-full'
      style={{
        display: 'flex',
        flexDirection: 'column',
        minHeight: '100%',
        backgroundColor: bgColor,
      }}
    >
      {/* 4. 内容行：flex + gap 必须在 style */}
      <Box
        className='flex items-center gap-3 px-4 py-3'
        style={{
          display: 'flex',
          alignItems: 'center',
          gap: 12 * wxScale,
          paddingLeft: 16 * wxScale,
          paddingRight: 16 * wxScale,
          paddingTop: 12 * wxScale,
          paddingBottom: 12 * wxScale,
        }}
      >
        {/* 5. 文本：fontSize 必须乘 wxScale */}
        <Text
          style={{
            fontSize: 16 * wxScale,
            fontWeight: 600,
            color: textColor,
          }}
        >
          标题文本
        </Text>
      </Box>
    </Box>
  )
}
```

## 七、验收标准

### Code Review Checklist

- [ ] **规则 1**：所有 flex/grid/position 布局属性在 style 中定义
- [ ] **规则 2**：className 中的布局关键类有 style 等效
- [ ] **规则 3**：fontSize/gap/padding 等视觉尺寸乘了 wxScale
- [ ] **规则 3**：flex/display/alignItems 等逻辑布局未乘 wxScale
- [ ] **原语使用**：使用 Box/Text/Image/Button，禁止 div/span/img/button
- [ ] **颜色动态**：颜色值在 style 中，支持 isDarkMode 切换

### 验收测试

1. 小程序开发者工具中打开服务页
2. 页面布局正确，无元素堆叠/挤压
3. 服务列表正常显示
4. 点击服务卡片可跳转详情页
