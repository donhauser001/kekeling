# 小程序页面改造规范

> 本规范基于 terminal-preview 组件库跨平台适配实践总结，适用于所有在小程序中渲染的页面组件。

---

## 一、核心原则

```
样式双写 + 图标用 props + 禁止 <style> 标签
```

---

## 二、七条硬性规则

### 规则 1：布局属性必须在 style 中定义

小程序不识别 Tailwind className，以下属性**必须**在 style 中完整表达：

| 类别 | 必须在 style 中的属性 |
|------|----------------------|
| Flex | `display`, `flexDirection`, `alignItems`, `justifyContent`, `gap`, `flex`, `flexWrap`, `flexShrink` |
| Grid | `display: 'grid'`, `gridTemplateColumns`, `gridGap` |
| 定位 | `position`, `top`, `right`, `bottom`, `left`, `zIndex` |
| 尺寸 | `width`, `height`, `minWidth`, `minHeight`, `maxWidth`, `maxHeight` |
| 溢出 | `overflow`, `overflowX`, `overflowY` |

```tsx
// ❌ 错误
<Box className='flex items-center gap-2'>

// ✅ 正确
<Box
  className='flex items-center gap-2'
  style={{
    display: 'flex',
    alignItems: 'center',
    gap: 8 * wxScale,
  }}
>
```

---

### 规则 2：className 不得作为布局的唯一来源

**允许单独使用**（非关键样式）：
- `text-sm`, `font-medium`, `rounded-lg`, `transition-all`

**禁止单独使用**（布局关键）：
- `flex`, `grid`, `block`, `hidden`
- `items-*`, `justify-*`, `gap-*`
- `w-*`, `h-*`, `p-*`, `m-*`
- `absolute`, `relative`, `fixed`, `sticky`

---

### 规则 3：wxScale 只用于视觉尺寸

```tsx
const wxScale = isWxEnvironment() ? 1.15 : 1
```

| 必须乘 wxScale | 禁止乘 wxScale |
|---------------|---------------|
| `fontSize` | `flex: 1` |
| `padding`, `margin`, `gap` | `display`, `flexDirection` |
| `borderRadius` | `alignItems`, `justifyContent` |
| `width`, `height`（固定像素值） | 百分比值如 `'100%'` |

```tsx
// ✅ 正确
style={{
  flex: 1,                    // 不乘
  fontSize: 14 * wxScale,     // 乘
  gap: 8 * wxScale,           // 乘
}}
```

---

### 规则 4：数据获取用 useState + useEffect

React Query 的 `useQuery` 在小程序中存在兼容性问题。

```tsx
// ❌ 错误
const { data } = useQuery({
  queryKey: ['services'],
  queryFn: () => api.getServices(),
})

// ✅ 正确
const [services, setServices] = useState([])
const [loading, setLoading] = useState(true)

useEffect(() => {
  api.getServices()
    .then(result => setServices(result.data || []))
    .catch(console.error)
    .finally(() => setLoading(false))
}, [])
```

---

### 规则 5：图标用 size 和 color props

`lucide-compat` 图标通过 `style.width/height` 设置尺寸**无效**。

```tsx
// ❌ 错误
<Star style={{ width: 12, height: 12, color: '#fbbf24' }} />

// ✅ 正确
<Star size={12 * wxScale} color="#fbbf24" />
```

---

### 规则 6：禁止使用 `<style>` 标签

小程序不支持内联 `<style>` 标签。

```tsx
// ❌ 错误
<style>{`.my-class { display: none; }`}</style>

// ✅ 正确（Web 环境条件渲染）
{isBrowserEnvironment() && (
  <style>{`.my-class { display: none; }`}</style>
)}

// ✅ 推荐（全局样式放 app.scss）
```

---

### 规则 7：圆形按钮用 Box + 固定宽高

小程序 Button 有默认样式，会导致圆形变椭圆。

```tsx
// ❌ 错误
<Button style={{ padding: 4, borderRadius: 9999 }}>
  <Heart size={12} />
</Button>

// ✅ 正确
<Box
  onClick={handleClick}
  style={{
    width: 22,
    height: 22,
    borderRadius: 11,  // 半径 = 宽度/2
    display: 'flex',
    alignItems: 'center',
    justifyContent: 'center',
  }}
>
  <Heart size={12} color="#fff" />
</Box>
```

## 三、组件使用规范

### 3.1 使用跨平台原语

```tsx
// ❌ 禁止
<div>, <span>, <img>, <button>

// ✅ 使用
import { Box, Text, Image, Button, ScrollView, Icon } from '../../ui/primitives'
```

### 3.2 标准组件结构

```tsx
import { Box, Text, Image } from '../../ui/primitives'
import { isWxEnvironment } from '../../platform/env'

const wxScale = isWxEnvironment() ? 1.15 : 1

export function MyComponent({ isDarkMode }: Props) {
  // 颜色变量
  const bgColor = isDarkMode ? '#1a1a1a' : '#ffffff'
  const textColor = isDarkMode ? '#e5e7eb' : '#1f2937'

  return (
    <Box
      className='flex flex-col min-h-full'
      style={{
        display: 'flex',
        flexDirection: 'column',
        minHeight: '100%',
        backgroundColor: bgColor,
      }}
    >
      <Text style={{ fontSize: 16 * wxScale, color: textColor }}>
        内容
      </Text>
    </Box>
  )
}
```

## 四、常见样式映射表

| Tailwind | Style | wxScale |
|----------|-------|---------|
| `flex` | `display: 'flex'` | ❌ |
| `flex-col` | `flexDirection: 'column'` | ❌ |
| `flex-1` | `flex: 1` | ❌ |
| `items-center` | `alignItems: 'center'` | ❌ |
| `justify-between` | `justifyContent: 'space-between'` | ❌ |
| `gap-2` | `gap: 8` | ✅ |
| `px-3` | `paddingLeft: 12, paddingRight: 12` | ✅ |
| `py-2` | `paddingTop: 8, paddingBottom: 8` | ✅ |
| `w-full` | `width: '100%'` | ❌ |
| `h-10` | `height: 40` | ✅ |
| `rounded-lg` | `borderRadius: 8` | ✅ |
| `text-sm` | `fontSize: 14` | ✅ |
| `font-medium` | `fontWeight: 500` | ❌ |
| `overflow-hidden` | `overflow: 'hidden'` | ❌ |
| `absolute` | `position: 'absolute'` | ❌ |
| `z-10` | `zIndex: 10` | ❌ |

## 五、Code Review 检查清单

- [ ] 所有 flex/grid/position 布局属性在 style 中定义
- [ ] className 中的布局类有 style 等效
- [ ] fontSize/gap/padding 等视觉尺寸乘了 wxScale
- [ ] flex/display 等逻辑布局未乘 wxScale
- [ ] 使用 useState + useEffect，不使用 useQuery
- [ ] 图标使用 `size` 和 `color` props
- [ ] 无 `<style>` 标签（或有 isBrowserEnvironment 判断）
- [ ] 圆形按钮使用 Box + 固定宽高
- [ ] 使用 Box/Text/Image，无 div/span/img
- [ ] 颜色支持 isDarkMode 切换

## 六、全局样式位置

隐藏滚动条等全局样式放在：

```
miniapp-shell/src/app.scss
```

示例：
```scss
.services-category-scroll::-webkit-scrollbar {
  display: none;
}
.services-category-scroll {
  scrollbar-width: none;
  -ms-overflow-style: none;
}
```
