## 一、概述

客服中心是连接用户与平台的核心沟通系统，承担用户服务质量监控、问题处理、评价管理等职责。

### 1.1 模块划分

| 模块 | 路由 | 优先级 | 状态 |
|------|------|--------|------|
| 在线客服 | `/support/chat` | P0 | 待开发 |
| 评价管理 | `/support/reviews` | P0 | 待开发 |
| 意见反馈 | `/support/feedback` | P1 | ✅ 已完成 |

### 1.3 核心设计原则

| 原则 | 说明 |
|------|------|
| **实时响应** | WebSocket 保证消息实时送达 |
| **统一入口** | 用户端一个客服入口，后台统一管理 |
| **可追溯** | 所有会话、消息、操作记录可查 |
| **智能辅助** | 快捷回复、常见问题，提升客服效率 |
| **数据驱动** | 评价统计、满意度分析，优化服务 |

## 五、实施计划

### 5.1 阶段规划

| 阶段 | 内容 | 工期 | 依赖 |

| 阶段 | 后端 | 前端 | 测试 |
|------|------|------|------|

| Phase 2 | 用户评价 API | 小程序评价提交页 | 评价流程测试 |

| Phase 6 | 快捷回复 API | 快捷回复配置页 | 效率提升测试 |

### 5.3 优先级说明

**为什么先做评价管理？**
1. 数据模型已存在（`EscortReview` 表）
2. 与订单流程紧密相关，完善用户闭环体验
3. 为陪诊员绩效考核提供数据支撑
4. 开发复杂度相对较低，可快速上线

**为什么在线客服排在后面？**
1. 需要 WebSocket 实时通信，技术复杂度高
2. 需要新建数据模型（会话、消息等）
3. 涉及用户端、后台双端开发
4. 但作为 P0 功能，评价完成后立即启动

## 七、接口规划

### 7.1 评价管理 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/reviews` | 评价列表（分页、筛选） |
| GET | `/admin/reviews/stats` | 评价统计 |
| GET | `/admin/reviews/:id` | 评价详情 |
| POST | `/admin/reviews/:id/hide` | 隐藏评价 |
| POST | `/admin/reviews/:id/show` | 显示评价 |
| GET | `/admin/reviews/ranking` | 陪诊员评分排行 |

### 7.2 在线客服 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/chat/sessions` | 会话列表 |
| GET | `/admin/chat/sessions/:id` | 会话详情（含消息） |
| POST | `/admin/chat/sessions/:id/close` | 关闭会话 |
| POST | `/admin/chat/sessions/:id/transfer` | 转接会话 |
| GET | `/admin/chat/quick-replies` | 快捷回复列表 |
| POST | `/admin/chat/quick-replies` | 创建快捷回复 |
| PUT | `/admin/chat/quick-replies/:id` | 更新快捷回复 |
| DELETE | `/admin/chat/quick-replies/:id` | 删除快捷回复 |

### 7.3 WebSocket 事件

| 事件 | 方向 | 说明 |
|------|------|------|
| `connect` | 双向 | 建立连接 |
| `new_session` | Server→Admin | 新会话通知 |
| `message` | 双向 | 消息发送/接收 |
| `typing` | 双向 | 正在输入状态 |
| `read` | 双向 | 消息已读 |
| `session_closed` | Server→Client | 会话结束 |

## 八、异常场景处理

### 8.1 在线客服

| 场景 | 处理方式 |
|------|---------|
| 用户掉线 | 保持会话5分钟，期间可重连继续 |
| 客服掉线 | 会话保持，其他客服可接入 |
| 无客服在线 | 显示提示，支持留言或自动转意见反馈 |
| 会话超时 | 30分钟无消息自动关闭，发送满意度评价邀请 |

### 8.2 评价管理

| 场景 | 处理方式 |
|------|---------|
| 敏感词过滤 | 自动检测，命中后标记待审核 |
| 恶意差评 | 客服可隐藏，用户侧不展示但保留记录 |
| 修改评价 | 订单完成7天内可修改一次 |
| 删除评价 | 用户可申请删除，需管理员审批 |
