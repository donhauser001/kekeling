## 一、功能概述

在线客服是用户与平台沟通的实时渠道，支持用户咨询、订单问题处理、投诉反馈等场景。

### 1.1 核心能力

| 能力 | 说明 |
|------|------|
| 实时通信 | WebSocket 保证消息即时送达 |
| 会话管理 | 排队、分配、转接、关闭 |
| 消息类型 | 文本、图片、订单卡片、快捷回复 |
| 智能辅助 | 快捷回复、常见问题推荐 |
| 数据分析 | 响应时间、满意度、会话量统计 |

### 1.2 用户场景

```
┌─────────────────────────────────────────────────────────────────────┐
│                        用户发起客服会话场景                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  场景1：服务咨询                                                     │
│  入口：服务详情页 → 底部「客服」按钮                                  │
│  特点：需要了解服务内容、价格、流程                                   │
│  上下文：自动携带当前服务信息                                         │

│  场景2：订单问题                                                     │
```

## 二、数据模型

### 2.1 ChatSession（客服会话）

```prisma
model ChatSession {
  id           String    @id @default(uuid())
  sessionNo    String    @unique @map("session_no")  // 会话编号 CS202501140001
  
  userId       String    @map("user_id")
  adminId      String?   @map("admin_id")            // 接待客服
  
  // 关联上下文
  orderId      String?   @map("order_id")
  serviceId    String?   @map("service_id")
  source       String    @default("profile")         // profile, service_detail, order_detail
  
  // 状态
  status       String    @default("waiting")         // waiting(排队), chatting(进行中), closed(已结束)
  
  // 时间节点
  startedAt    DateTime? @map("started_at")          // 客服接入时间
  closedAt     DateTime? @map("closed_at")           // 结束时间
  closeReason  String?   @map("close_reason")        // user_close, admin_close, timeout
  
  // 满意度评价
  rating       Int?                                  // 1-5 满意度
  ratingContent String? @map("rating_content")       // 评价内容
  
  // 统计字段
  messageCount Int       @default(0) @map("message_count")
  firstReplyAt DateTime? @map("first_reply_at")      // 首次回复时间（计算响应速度）
  
  createdAt    DateTime  @default(now()) @map("created_at")
  updatedAt    DateTime  @updatedAt @map("updated_at")

  // 关联
  user         User      @relation(fields: [userId], references: [id])
  admin        Admin?    @relation(fields: [adminId], references: [id])
  order        Order?    @relation(fields: [orderId], references: [id])
  service      Service?  @relation(fields: [serviceId], references: [id])
  messages     ChatMessage[]

  @@index([userId, status])
  @@index([adminId, status])
  @@index([status, createdAt])
  @@map("chat_sessions")
}
```

### 2.2 ChatMessage（聊天消息）

```prisma
model ChatMessage {
  id           String    @id @default(uuid())
  sessionId    String    @map("session_id")
  
  senderType   String    @map("sender_type")         // user, admin, system
  senderId     String?   @map("sender_id")           // 发送者ID
  
  type         String    @default("text")            // text, image, file, order_card, service_card, quick_reply
  content      String    @db.Text                    // 消息内容
  extra        Json?                                 // 扩展信息
  // text: null
  // image: { url, width, height, thumbnail }
  // file: { url, name, size, mimeType }
  // order_card: { orderId, orderNo, serviceName, status }
  // service_card: { serviceId, name, price, image }
  
  isRead       Boolean   @default(false) @map("is_read")
  readAt       DateTime? @map("read_at")
  
  createdAt    DateTime  @default(now()) @map("created_at")

  session      ChatSession @relation(fields: [sessionId], references: [id], onDelete: Cascade)

  @@index([sessionId, createdAt])
  @@index([sessionId, isRead])
  @@map("chat_messages")
}
```

### 2.3 QuickReply（快捷回复）

```prisma
model QuickReply {
  id           String    @id @default(uuid())
  
  category     String    @default("other")           // greeting(问候语), order(订单相关), payment(支付相关), service(服务相关), other
  title        String                                // 标题（供客服选择用）
  content      String    @db.Text                    // 回复内容
  
  useCount     Int       @default(0) @map("use_count") // 使用次数
  
  sort         Int       @default(0)
  status       String    @default("active")          // active, inactive
  
  createdAt    DateTime  @default(now()) @map("created_at")
  updatedAt    DateTime  @updatedAt @map("updated_at")

  @@index([category, status])
  @@map("quick_replies")
}
```

## 三、后端接口

### 3.1 会话管理

```typescript
// 获取会话列表（后台）
GET /admin/chat/sessions
Query: { status?, adminId?, userId?, page?, pageSize? }
Response: { items: ChatSession[], total, page, pageSize }

// 获取会话详情（含消息）
GET /admin/chat/sessions/:id
Response: { session: ChatSession, messages: ChatMessage[] }

// 接入会话
POST /admin/chat/sessions/:id/accept
Response: { session: ChatSession }

// 关闭会话
POST /admin/chat/sessions/:id/close
Body: { reason?: string }

// 转接会话
POST /admin/chat/sessions/:id/transfer
Body: { targetAdminId: string }

// 获取统计数据
GET /admin/chat/stats
Response: { waiting, chatting, todayTotal, avgResponseTime, avgRating }
```

### 3.2 快捷回复管理

```typescript
// 列表
GET /admin/chat/quick-replies
Query: { category?, status?, page?, pageSize? }

// 创建
POST /admin/chat/quick-replies
Body: { category, title, content, sort? }

// 更新
PUT /admin/chat/quick-replies/:id
Body: { category?, title?, content?, sort?, status? }

// 删除
DELETE /admin/chat/quick-replies/:id

// 使用（增加计数）
POST /admin/chat/quick-replies/:id/use
```

### 3.3 用户端 API

```typescript
// 创建会话
POST /chat/sessions
Body: { source, orderId?, serviceId? }
Response: { session: ChatSession }

// 获取当前进行中的会话
GET /chat/sessions/current
Response: { session: ChatSession | null }

// 获取历史会话列表
GET /chat/sessions/history
Query: { page?, pageSize? }

// 获取会话消息
GET /chat/sessions/:id/messages
Query: { before?, limit? }

// 评价会话
POST /chat/sessions/:id/rate
Body: { rating: number, content?: string }
```

## 四、WebSocket 协议

### 4.1 连接建立

```typescript
// 用户端连接
ws://api.example.com/chat?token=<jwt>&type=user

// 后台客服连接
ws://api.example.com/chat?token=<jwt>&type=admin

// 连接成功响应
{
  event: "connected",
  data: { sessionId?, unreadCount }
}
```

### 4.2 事件定义

#### 用户 → 服务器

| 事件 | 数据 | 说明 |
|------|------|------|
| `send_message` | `{ sessionId, type, content, extra? }` | 发送消息 |
| `typing` | `{ sessionId }` | 正在输入 |
| `read` | `{ sessionId, messageId }` | 标记已读 |

#### 服务器 → 用户

| 事件 | 数据 | 说明 |
|------|------|------|
| `new_message` | `{ message: ChatMessage }` | 收到新消息 |
| `session_accepted` | `{ session, admin }` | 客服已接入 |
| `session_closed` | `{ sessionId, reason }` | 会话已关闭 |
| `admin_typing` | `{ sessionId }` | 客服正在输入 |

#### 客服 → 服务器

| 事件 | 数据 | 说明 |
|------|------|------|
| `send_message` | `{ sessionId, type, content, extra? }` | 发送消息 |
| `accept_session` | `{ sessionId }` | 接入会话 |
| `close_session` | `{ sessionId, reason? }` | 关闭会话 |
| `transfer_session` | `{ sessionId, targetAdminId }` | 转接会话 |
| `typing` | `{ sessionId }` | 正在输入 |

#### 服务器 → 客服

| 事件 | 数据 | 说明 |
|------|------|------|
| `new_session` | `{ session: ChatSession }` | 新会话通知 |
| `new_message` | `{ message: ChatMessage }` | 收到新消息 |
| `session_transferred` | `{ session }` | 收到转接会话 |
| `user_typing` | `{ sessionId }` | 用户正在输入 |
| `user_disconnected` | `{ sessionId }` | 用户断开连接 |

## 七、技术实现要点

### 7.1 WebSocket Gateway (NestJS)

```typescript
@WebSocketGateway({
  cors: true,
  namespace: '/chat',
})
export class ChatGateway implements OnGatewayConnection, OnGatewayDisconnect {
  @WebSocketServer()
  server: Server;

  // 用户房间: user_${userId}
  // 客服房间: admin_${adminId}
  // 会话房间: session_${sessionId}

  async handleConnection(client: Socket) {
    // 验证 token，加入对应房间
  }

  @SubscribeMessage('send_message')
  async handleMessage(client: Socket, payload: SendMessageDto) {
    // 保存消息，广播到会话房间
  }
}
```

### 7.2 消息持久化

- 所有消息入库，保证可追溯
- 消息状态（发送中→已发送→已读）
- 支持消息撤回（可选）

### 7.3 会话分配策略

```typescript
// 简单策略：按会话数平均分配
async assignSession(sessionId: string) {
  const availableAdmins = await this.getOnlineAdmins();
  const admin = availableAdmins.sort(
    (a, b) => a.currentSessionCount - b.currentSessionCount
  )[0];
  
  if (admin) {
    await this.assignToAdmin(sessionId, admin.id);
  }
}
```

### 7.4 断线重连

- 用户断线：保持会话状态5分钟
- 客服断线：会话可被其他客服接入
- 重连后自动同步未读消息
