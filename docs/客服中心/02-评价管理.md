## 一、功能概述

评价管理系统负责用户对陪诊服务的评价收集、展示、审核，以及陪诊员服务质量的数据分析。

### 1.1 核心能力

| 能力 | 说明 |
|------|------|
| 评价收集 | 订单完成后引导用户评价 |
| 评价展示 | 陪诊员详情页展示评价 |
| 评价审核 | 敏感内容过滤、差评处理 |
| 陪诊员回复 | 陪诊员可回复用户评价 |
| 数据统计 | 评分分布、趋势分析、排行榜 |

### 1.2 评价流程

## 七、业务规则

### 7.1 评价时机

| 规则 | 说明 |
|------|------|
| 触发条件 | 订单状态变为「已完成」 |
| 评价时限 | 订单完成后 30 天内可评价 |
| 修改时限 | 提交后 7 天内可修改一次 |
| 提醒机制 | 完成后 2小时、24小时、7天 推送提醒 |

### 7.2 评价展示规则

| 规则 | 说明 |
|------|------|
| 默认展示 | 按时间倒序 |
| 隐藏处理 | 后台隐藏后，用户端不展示但保留记录 |
| 匿名展示 | 用户昵称显示部分（张**） |
| 图片数量 | 最多6张 |

### 7.3 评分计算规则

```typescript
// 陪诊员评分计算
function calculateEscortRating(reviews: Review[]): number {
  if (reviews.length === 0) return 5.0;  // 默认5分
  
  const sum = reviews.reduce((acc, r) => acc + r.rating, 0);
  const avg = sum / reviews.length;
  
  // 保留一位小数
  return Math.round(avg * 10) / 10;
}

// 好评率计算（4-5星为好评）
function calculateGoodRate(reviews: Review[]): number {
  if (reviews.length === 0) return 100;
  
  const goodCount = reviews.filter(r => r.rating >= 4).length;
  return Math.round((goodCount / reviews.length) * 100);
}
```

### 7.4 敏感词处理

- 提交时检测敏感词
- 命中敏感词：标记待审核，用户侧正常展示但后台可见
- 严重违规词：直接隐藏，通知用户修改

```typescript
  });
  
  // 设置定时提醒（2小时后、24小时后）
  await this.scheduleReminderNotification(order.id, '2h');
  await this.scheduleReminderNotification(order.id, '24h');
}
```
