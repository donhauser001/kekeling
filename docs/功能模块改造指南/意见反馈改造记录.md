## 2. 改造内容

### 2.1 前端改造

#### 文件结构（拆分后）

按照规则 12（大文件拆分），将原 787 行的 `FeedbackPage.tsx` 拆分为模块化结构：

```
feedback/
├── index.ts               # 导出（8行）
├── types.ts               # 类型定义（25行）
├── constants.ts           # 常量和工具函数（36行）
├── FeedbackHeader.tsx     # 导航栏组件（54行）
├── FeedbackSkeleton.tsx   # 骨架屏组件（56行）
├── FeedbackSuccess.tsx    # 成功状态组件（96行）
├── FeedbackForm.tsx       # 表单组件（361行）
└── FeedbackPage.tsx       # 主组件（155行）
```

**拆分收益**：
- 每个文件职责单一，便于维护
- 主组件从 787 行降至 155 行
- 消除重复代码（导航栏提取为 `FeedbackHeader`）
- 跨平台 Toast 工具函数统一封装

#### 改造内容

1. **遵循小程序规范**
   - 使用原语组件 `Box`, `Text`, `Icon`, `Textarea`, `Image`, `Input`
   - 布局属性在 `style` 中定义
   - 使用 `wxScale` 缩放视觉尺寸
   - 使用 `useState` + `useEffect` 管理状态

2. **页面功能**
   - 反馈类型选择（功能建议、问题反馈、服务相关、体验优化、其他）
   - 反馈内容输入（最少10字，最多500字）
   - 截图上传（最多9张）
   - 联系方式填写（可选）
   - 提交成功状态展示

3. **导航栏规范**
   - 使用主色背景（`primaryColor`）
   - 标题居中
   - 左侧返回按钮使用 `Icon name="left"`
   - 预留小程序安全区域（`wxSafeAreaTop`）

#### 数据库模型

```prisma
model Feedback {
  id        String   @id @default(uuid())
  userId    String?  @map("user_id")
  type      String   // suggestion, bug, service, experience, other
  content   String   @db.Text
  contact   String?
  images    String[] @default([])
  status    String   @default("pending") // pending, processing, resolved, closed
  
  // 处理信息
  handlerId   String?   @map("handler_id")
  handlerName String?   @map("handler_name")
  handleNote  String?   @map("handle_note")
  handledAt   DateTime? @map("handled_at")
  
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  user      User?    @relation(fields: [userId], references: [id])

  @@index([userId])
  @@index([type])
  @@index([status])
  @@map("feedbacks")
}
```

## 6. 管理后台

### 6.1 后台功能

管理后台已实现反馈管理功能，位于 **客服中心 → 意见反馈** (`/support/feedback`)。

#### 功能列表

| 功能 | 说明 |
|------|------|
| 统计卡片 | 待处理、处理中、已解决、已关闭数量 |
| 状态筛选 | 按反馈状态过滤列表 |
| 类型筛选 | 按反馈类型过滤列表 |
| 查看详情 | 显示反馈内容、截图、用户信息 |
| 处理反馈 | 设置状态（处理中/已解决/已关闭）和备注 |

#### 后台 API

| 接口名称 | 方法 | 路径 | 功能 |
|----------|------|------|------|
| 反馈列表 | GET | `/admin/feedback` | 获取反馈列表（分页、筛选） |
| 反馈统计 | GET | `/admin/feedback/stats` | 获取各状态数量统计 |
| 反馈详情 | GET | `/admin/feedback/:id` | 获取单条反馈详情 |
| 处理反馈 | POST | `/admin/feedback/:id/handle` | 更新反馈状态和处理备注 |

#### 相关文件

| 文件路径 | 说明 |
|----------|------|
| `server/src/modules/admin/controllers/admin-feedback.controller.ts` | 后台 API 控制器 |
| `server/src/modules/admin/services/admin-feedback.service.ts` | 后台业务逻辑 |
| `src/features/feedback/index.tsx` | 前端管理页面 |
| `src/routes/_authenticated/support/feedback.tsx` | 路由配置 |
| `src/components/layout/data/sidebar-data.ts` | 菜单配置（客服中心→意见反馈） |
