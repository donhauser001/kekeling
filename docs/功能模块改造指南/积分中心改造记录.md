## 二、改造内容

### 2.1 API 路径修正

**问题**：前端调用 `/marketing/points/*`，后端实际路由是 `/points/*`

**修复前**：
```typescript
// ❌ 错误路径
return await userRequest('/marketing/points/my')
return await userRequest('/marketing/points/records')
```

**修复后**：
```typescript
// ✅ 正确路径
return await userRequest('/points/overview')
return await userRequest('/points/records')
```

### 2.2 数据结构对齐

**后端返回结构（PointsService.getPointsOverview）**：
```typescript
{
  totalPoints: number      // 累计获得
  usedPoints: number       // 累计使用
  expiredPoints: number    // 已过期
  currentPoints: number    // 当前余额
  expiringPoints: number   // 即将过期（7天内）
}
```

**前端期望结构（PointsInfo）**：
```typescript
{
  balance: number          // 当前余额
  totalEarned: number      // 累计获得
  totalUsed: number        // 累计使用
  expiringSoon: number     // 即将过期
}
```

**转换代码**：
```typescript
export const getMyPoints = async (): Promise<PointsInfo> => {
  const data = await userRequest<BackendPointsOverview>('/points/overview')
  return {
    balance: data.currentPoints,
    totalEarned: data.totalPoints,
    totalUsed: data.usedPoints,
    expiringSoon: data.expiringPoints,
  }
}
```

### 2.3 新增签到功能

**新增 API**：

```typescript
// 获取签到状态
export const getCheckInStatus = async (): Promise<CheckInStatus> => {
  return await userRequest<CheckInStatus>('/points/checkin/status')
}

// 每日签到
export const checkIn = async (): Promise<{ success: boolean; data?: CheckInResult; message?: string }> => {
  const data = await userRequest<CheckInResult>('/points/checkin', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({}),
  })
  return { success: true, data }
}
```

**新增类型定义**：

```typescript
interface CheckInStatus {
  checkedIn: boolean        // 今日是否已签到
  consecutiveDays: number   // 连续签到天数
  todayPoints: number       // 今日获得积分
}

interface CheckInResult {
  points: number            // 获得积分
  consecutiveDays: number   // 连续签到天数
  totalPoints: number       // 当前总积分
}
```

### 2.5 积分记录数据结构更新

**修复前（旧结构）**：
```typescript
interface PointsRecord {
  id: string
  title: string      // ❌ 后端返回的是 description
  points: number
  type: 'earn' | 'use'
  createdAt: string
}

interface PointsRecordsResponse {
  items: PointsRecord[]  // ❌ 后端返回的是 data
  total: number
}
```

**修复后（与后端一致）**：
```typescript
interface PointsRecord {
  id: string
  points: number
  balance: number
  type: 'earn' | 'use' | 'expire' | 'refund'
  source: string
  sourceId?: string
  description: string
  expireAt?: string
  createdAt: string
}

interface PointsRecordsResponse {
  data: PointsRecord[]
  total: number
  page: number
  pageSize: number
}
```
