## 八、迁移架构规范

### 8.1 迁移总原则（四条红线）

> ⚠️ **架构纪律**：以下四条原则为迁移过程中的硬性约束，违反任一条即为架构退化。

#### 红线 1：业务逻辑不得下沉到宿主

- 小程序里**不允许**出现任何订单/营销/工作台的业务判断（if/else 流转、字段拼装等）
- 宿主只负责：**登录/支付/分享/定位/扫码/文件/存储/导航/提示**
- 所有业务逻辑必须保留在 Domain 层（终端预览器）

#### 红线 2：桥接层是唯一宿主入口

- 小程序侧**禁止直接调用** `wx.xxx`
- 必须经 `WxBridge` 接口（已建好：`src/components/terminal-preview/bridge/`）
- 页面侧对宿主能力零感知

#### 红线 3：终端预览器是主干，宿主工程是薄壳

- 预览器代码为**主仓主分支**
- 小程序工程只做集成与适配
- **不允许**出现"为了小程序更好用而改一套页面"的分叉
- 同一页面在 Web 预览器与小程序必须同一份组件渲染

#### 红线 4：API 通道不变

- `userRequest` / `escortRequest` 仍是数据入口
- 小程序只替换底层 request 实现，**不改变业务层调用方式**
- Token 管理机制保持一致

**统一错误码规范**（页面不需要判断 wx 的 error message）：

```typescript
// miniapp-shell/src/runtime/bridge-impl.ts

/** 桥接层统一错误码 */
export enum BridgeErrorCode {
  SUCCESS = 0,
  PERMISSION_DENIED = 1001,  // 用户拒绝授权（如拒绝定位、相机权限）
  CANCELLED = 1002,          // 用户取消操作（如取消支付、取消选择图片）
  UNAVAILABLE = 1003,        // 能力不可用（如设备不支持某功能）
  NETWORK_ERROR = 1004,      // 网络错误
  TIMEOUT = 1005,            // 操作超时
  UNKNOWN = 9999,            // 未知错误
}

/** 桥接层统一错误类 */
export class BridgeError extends Error {
  code: BridgeErrorCode
  originalError?: unknown  // 仅用于调试
  get isCancelled(): boolean  // 便捷判断
  get isPermissionDenied(): boolean
}
```

**错误映射规则**：

| wx errMsg 关键词 | BridgeErrorCode | 说明 |
|-----------------|-----------------|------|
| `cancel` / `user deny` | CANCELLED | 用户取消 |
| `auth deny` / `authorize` / `permission` | PERMISSION_DENIED | 拒绝授权 |
| `timeout` | TIMEOUT | 超时 |
| `network` / `request:fail` | NETWORK_ERROR | 网络错误 |
| `not support` / `not available` | UNAVAILABLE | 能力不可用 |
| 其他 | UNKNOWN | 未知错误 |

**业务层使用示例**：

```typescript
import { BridgeError, BridgeErrorCode } from '@/runtime'

try {
  const result = await wxBridge.chooseImage({ count: 1 })
} catch (err) {
  if (err instanceof BridgeError) {
    if (err.isCancelled) return  // 用户取消，静默处理
    if (err.isPermissionDenied) {
      wxBridge.showModal({ title: '提示', content: '请授权相册权限' })
      return
    }
    wxBridge.showToast({ title: err.message })
  }
}
```
