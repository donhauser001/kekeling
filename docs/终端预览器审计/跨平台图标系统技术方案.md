# 跨平台图标系统技术方案 · 决策冻结版

> **决策状态**：✅ 已冻结  
> **生效日期**：2024-12-18  
> **决策内容**：本方案自即日起作为唯一图标实现方式，`lucide-react` 在小程序侧**禁止使用**。

---

## 〇、执行摘要

| 项目 | 决策 |
|------|------|
| **技术选型** | iconfont 字体图标 |
| **Web 实现** | `<i>` 标签 + CSS class |
| **小程序实现** | `<Text>` + Unicode 字符 |
| **字体加载** | `wx.loadFontFace` (仅 app.ts) |
| **退出策略** | 小程序构建禁止 `lucide-react` |
| **实施周期** | 3-4 天 |

## 一、问题分析

### 1.1 当前状态

| 平台 | 当前方案 | 问题 |
|------|---------|------|
| Web (terminal-preview) | lucide-react SVG 组件 | ✅ 正常工作 |
| 小程序 (miniapp-shell) | 需要适配 | ❌ SVG 不支持，需要替代方案 |

### 1.2 核心矛盾

```
lucide-react = SVG = Web Only
小程序 = 没有 SVG 生态
强行兼容 = 技术债 + 不稳定
```

**结论**：选择"工程确定性"，而非"技术 Hack"。

### 1.3 需求

1. 图标视觉一致（同一套设计语言）
2. 支持动态颜色（根据主题色变化）
3. 支持动态大小
4. 维护成本低（一处更新，多端生效）
5. 性能优良（不影响加载速度）

---

## 二、技术方案对比

### 方案 A：Iconfont 字体图标 ⭐ **最终选型**

| 评估维度 | 得分 | 说明 |
|---------|------|------|
| 跨平台一致性 | ⭐⭐⭐⭐⭐ | Web/小程序/RN 均支持 |
| 动态颜色 | ⭐⭐⭐⭐⭐ | CSS color 直接控制 |
| 动态大小 | ⭐⭐⭐⭐⭐ | CSS font-size 直接控制 |
| 维护成本 | ⭐⭐⭐⭐☆ | iconfont.cn 可视化管理 |
| 性能 | ⭐⭐⭐⭐☆ | 字体文件约 20-50KB |
| 风险 | ⭐⭐⭐⭐⭐ | 极低，技术成熟 |

### 方案 B-E：已否决

| 方案 | 否决原因 |
|------|---------|
| SVG Symbol + Use | 小程序不支持 `<svg>` 和 `<use>` |
| PNG/Base64 图片 | 不支持动态颜色，维护成本高 |
| Iconify 云服务 | 依赖外部网络，小程序不可用 |
| 自建构建流水线 | 初期投入大，ROI 不合理 |

## 四、强制约束规范 ⚠️

### 4.1 API 约束（冻结）

```typescript
// ✅ 唯一允许的 Icon 使用方式
interface IconProps {
  name: IconName        // 必填，强类型
  size?: number         // px，默认 24
  color?: string        // 默认 currentColor
  className?: string    // 可选
}

// 使用示例
<Icon name="home" size={24} color="#333" />
```

**禁止行为**：

```typescript
// ❌ 禁止：业务组件直接 import iconfont.css
import '../assets/iconfont/iconfont.css'

// ❌ 禁止：业务组件直接使用 Text/i 渲染图标
<Text className="iconfont icon-home" />
<i className="iconfont icon-home" />

// ❌ 禁止：硬编码 Unicode
<Text>{'\ue600'}</Text>
```

### 4.3 小程序字体加载方式（唯一）

> **决策**：只使用 `wx.loadFontFace`，在 `app.ts` 中执行一次。

```typescript
// miniapp-shell/src/app.ts
class App extends Component {
  componentDidMount() {
    // 唯一的字体加载入口
    if (process.env.TARO_ENV === 'weapp') {
      wx.loadFontFace({
        global: true,
        family: 'iconfont',
        source: 'url("https://cdn.kekeling.com/fonts/iconfont.ttf")',
        success: () => console.log('[iconfont] 字体加载成功'),
        fail: (err) => console.error('[iconfont] 字体加载失败', err),
      })
    }
  }
}
```

**优势**：
- ✅ CDN 字体 = 可控缓存
- ✅ 不进包体积（小程序包大小敏感）
- ✅ 不污染全局 CSS
- ✅ 单一入口，便于追踪

**禁止**：
- ❌ 在组件级别加载字体
- ❌ 使用 `@font-face` CSS 方式（进包）
- ❌ 使用本地字体文件（包体积）

### 4.4 lucide-react 退出策略

> **决策**：小程序构建中 `lucide-react` 必须是**硬错误**。

**实现方式**：Webpack `NormalModuleReplacementPlugin`

```typescript
// miniapp-shell/config/index.ts
webpackChain(chain) {
  // lucide-react 在小程序中禁止使用
  chain.plugin('block-lucide-react').use(
    new webpack.NormalModuleReplacementPlugin(
      /lucide-react/,
      (resource) => {
        throw new Error(
          `[构建错误] 小程序禁止使用 lucide-react！\n` +
          `文件: ${resource.context}\n` +
          `请改用: import { Icon } from '@/ui/primitives'`
        )
      }
    )
  )
}
```

**效果**：
```bash
# 如果有人在小程序代码中 import lucide-react
$ pnpm build:weapp

ERROR in ./src/components/SomeComponent.tsx
[构建错误] 小程序禁止使用 lucide-react！
文件: /src/components/SomeComponent.tsx
请改用: import { Icon } from '@/ui/primitives'
```

### 5.3 同步脚本

```typescript
// scripts/sync-iconfont.ts
import fs from 'fs'
import path from 'path'

interface IconFontGlyph {
  icon_id: string
  name: string
  font_class: string
  unicode: string
  unicode_decimal: number
}

interface IconFontConfig {
  id: string
  name: string
  font_family: string
  css_prefix_text: string
  glyphs: IconFontGlyph[]
}

const ICONFONT_JSON_PATH = 'src/shared/assets/iconfont/iconfont.json'
const ICON_TYPES_PATH = 'src/shared/types/icon.ts'
const ICON_UNICODE_PATH = 'miniapp-shell/src/constants/icon-unicode.ts'

async function syncIconfont() {
  console.log('🔄 开始同步 iconfont...')

  // 1. 读取 iconfont.json
  const configPath = path.resolve(process.cwd(), ICONFONT_JSON_PATH)
  if (!fs.existsSync(configPath)) {
    console.error('❌ 未找到 iconfont.json，请先从 iconfont.cn 下载')
    process.exit(1)
  }

  const config: IconFontConfig = JSON.parse(fs.readFileSync(configPath, 'utf-8'))
  console.log(`📦 找到 ${config.glyphs.length} 个图标`)

  // 2. 生成 TypeScript 类型
  const iconNames = config.glyphs
    .map(g => `  | '${g.font_class}'`)
    .join('\n')

  const typeContent = `/**
 * 图标名称类型定义
 * 
 * ⚠️ 自动生成，请勿手动修改
 * 
 * 更新方式：
 * 1. 在 iconfont.cn 添加/修改图标
 * 2. 下载新的字体文件和 iconfont.json
 * 3. 运行 pnpm sync:iconfont
 * 
 * @generated from iconfont.json
 */
export type IconName =
${iconNames}
`

  fs.writeFileSync(path.resolve(process.cwd(), ICON_TYPES_PATH), typeContent)
  console.log(`✅ 已生成类型定义: ${ICON_TYPES_PATH}`)

  // 3. 生成 Unicode 映射
  const unicodeMap = config.glyphs.reduce((acc, g) => {
    // 转换为 JavaScript Unicode 转义
    acc[g.font_class] = `\\u${g.unicode}`
    return acc
  }, {} as Record<string, string>)

  const unicodeContent = `/**
 * 图标 Unicode 映射
 * 
 * ⚠️ 自动生成，请勿手动修改
 * 
 * @generated from iconfont.json
 */
import type { IconName } from '@/shared/types/icon'

export const iconUnicode: Record<IconName, string> = ${JSON.stringify(unicodeMap, null, 2).replace(/\\\\u/g, '\\u')}
`

  fs.writeFileSync(path.resolve(process.cwd(), ICON_UNICODE_PATH), unicodeContent)
  console.log(`✅ 已生成 Unicode 映射: ${ICON_UNICODE_PATH}`)

  console.log('🎉 iconfont 同步完成！')
}

syncIconfont().catch(console.error)
```

  }

## 八、FAQ

### Q1: 如何添加新图标？

1. 登录 [iconfont.cn](https://www.iconfont.cn/)
2. 在项目中搜索并添加图标（或上传自定义 SVG）
3. 点击"下载至本地"
4. 替换 `shared/assets/iconfont/` 下的文件
5. 运行 `pnpm sync:iconfont`
6. 使用 `<Icon name="new-icon" />`

### Q2: 如何保证 Web 和小程序图标一致？

使用同一套 iconfont 资源文件，只是渲染方式不同：
- Web：`<i>` 标签 + CSS class
- 小程序：`<Text>` 标签 + Unicode 字符

### Q3: 字体文件太大怎么办？

1. 只选择需要的图标（iconfont.cn 支持按需选择）
2. 使用 WOFF2 格式（比 TTF 小 30%）
3. 开启 CDN Gzip 压缩
4. 利用浏览器缓存

### Q4: 多色图标怎么处理？

字体图标不支持多色。对于多色图标（如品牌 Logo），使用 PNG 图片：

```tsx
// 多色图标使用 Image
<Image src="/assets/logo-color.png" />

// 单色图标使用 Icon
<Icon name="home" color="#333" />
```

### Q5: 能否在 Web 端继续使用 lucide-react？

**可以**，但仅限于：
- 纯 Web 组件（不在 `terminal-preview` 中）
- 不参与跨平台的独立模块

`terminal-preview` 内的所有图标必须使用 `<Icon>` primitive。

## 附录 B：iconfont.cn 操作指南

### B.1 创建项目

1. 访问 https://www.iconfont.cn/
2. 登录账号（支持 GitHub）
3. 进入「我的项目」→「新建项目」
4. 项目名称：`kekeling-icons`
5. 前缀：`icon-`

### B.2 添加图标

1. 在图标库搜索（推荐搜索 "lucide" 或 "feather"）
2. 鼠标悬停图标，点击「添加入库」
3. 在购物车中点击「添加至项目」
4. 选择 `kekeling-icons` 项目

### B.3 下载字体

1. 进入项目详情
2. 点击「Font Class」标签
3. 点击「下载至本地」
4. 解压后获得完整字体文件
