## 核心创新点摘要

### 1. 多角色视角切换机制
- 用户视角 ↔ 服务提供者视角 一键切换
- 基于 Token 自动推导视角角色
- 预览器与真实终端安全隔离

### 2. 双通道会话模拟架构
- 双 Token 并存（userToken + escortToken）
- 自动选择请求通道
- Mock Token 检测与数据隔离

### 3. 三层数据覆盖机制
- 优先级：Props 覆盖 > API 数据 > 默认值
- 支持局部覆盖（Partial 类型）
- 配置即时同步到预览界面

### 4. 页面路由注册表
- 终端与预览器的单一真源
- 30+ 页面统一管理
- 入口权限与参数校验

### 5. 内置调试面板
- 实时显示视角/Token/通道状态
- 支持 Token 注入/清除
- 开发环境自动启用
