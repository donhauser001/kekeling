## 六、Mermaid 版本流程图

> 以下是 Mermaid 格式的流程图，可直接在支持 Mermaid 的文档中渲染

### 6.1 视角推导流程 (Mermaid)

```mermaid
flowchart TD
    A[开始] --> B[读取输入参数]
    B --> C{Props 中是否显式<br/>指定 viewerRole?}
    
    C -->|是| D[使用 Props 值<br/>effectiveRole = viewerRole]
    C -->|否| E{escortSession.token<br/>是否存在?}
    
    E -->|是| F{验证 escortToken<br/>是否有效?}
    E -->|否| G[effectiveRole = 'user']
    
    F -->|有效| H[effectiveRole = 'escort']
    F -->|无效| G
    
    D --> I[返回推导结果]
    G --> I
    H --> I
    
    I --> J[结束]
```

### 6.2 双通道请求流程 (Mermaid)

```mermaid
flowchart TD
    A[发起 API 请求] --> B[读取当前视角角色]
    B --> C{effectiveViewerRole<br/>== 'escort'?}
    
    C -->|是| D[选择 escortRequest 通道]
    C -->|否| E[选择 userRequest 通道]
    
    D --> F[获取 escortToken]
    E --> G[获取 userToken]
    
    F --> H{isMockToken?}
    G --> I{isMockToken?}
    
    H -->|是| J[返回 Mock 数据]
    H -->|否| K[调用真实 API]
    
    I -->|是| L[返回 Mock 数据]
    I -->|否| M[调用真实 API]
    
    J --> N[返回请求结果]
    K --> N
    L --> N
    M --> N
```

### 6.3 数据合并流程 (Mermaid)

```mermaid
flowchart TD
    A[开始数据合并] --> B[加载默认值数据<br/>defaultSettings]
    B --> C{API 数据<br/>是否已加载?}
    
    C -->|是| D[合并 API 数据<br/>...default + ...apiData]
    C -->|否| E[使用默认值<br/>...default]
    
    D --> F{Props 覆盖<br/>是否存在?}
    E --> F
    
    F -->|是| G[合并 Props 覆盖<br/>...current + ...override]
    F -->|否| H[使用当前结果]
    
    G --> I[返回最终结果<br/>finalSettings]
    H --> I
    
    I --> J[结束]
```
